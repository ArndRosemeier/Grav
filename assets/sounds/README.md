# Sounds

Made with OpenRouter, model `bytedance-seed/seed-audio-1-0` (2026-11-16), then
trimmed, levelled to -18 LUFS and stored as mono Ogg Vorbis. To make one
again: `python3 or.py sfx "<prompt>" --model <id> --out x.mp3`.
